# htj2k

A High-Throughput JPEG 2000 (HTJ2K, ITU-T T.814 | ISO/IEC 15444-15)
codestream codec in safe Rust, ported from
[OpenJPH](https://github.com/aous72/OpenJPH) 0.33.0.

Work in progress.
